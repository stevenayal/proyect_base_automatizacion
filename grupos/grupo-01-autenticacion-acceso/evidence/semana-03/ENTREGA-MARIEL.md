# Entrega de Mariel Aquino — Semana 03

## Aclaración de trazabilidad

El aporte de Mariel Aquino correspondiente a los entregables API de la Semana 03 fue incorporado anticipadamente al repositorio mediante el PR de Semana 02 y el commit `1f33f88` (`feat: agrega trazabilidad BDD-API y coleccion postman`).

Esta constancia permite que el aporte quede identificado dentro de la entrega grupal de Semana 03 sin duplicar la colección ni reescribir el historial ya fusionado en `main`.

## Contenido del aporte

- Colección: [`postman/grupo-01-autenticacion.postman_collection.json`](../../../../postman/grupo-01-autenticacion.postman_collection.json).
- Escenario happy path: login exitoso con credenciales válidas.
- Escenario negativo: recuperación de contraseña con correo no registrado.
- Escenario edge case: cierre de sesión con token expirado.
- Trazabilidad BDD → API documentada en el README del grupo.
- Variables de ejecución: `baseUrl`, `candidateId` y `sessionId`.

## Ubicación correcta

Aunque el cambio original entró al repositorio a través del PR de Semana 02, por su contenido funcional forma parte de la entrega API con Postman de la **Semana 03**.
