# Flujo semanal de trabajo

## Rama sugerida por grupo

- `grupo-a/semana-1`
- `grupo-a/semana-2`
- `grupo-b/semana-1`

## Entrega

1. Crear rama semanal.
2. Implementar avances de BDD, API o UI.
3. Subir evidencias en `evidence/`.
4. Abrir 1 PR por semana.
5. Usar la plantilla de PR del repo.

## Objetivo por semana

### Semana 1

- análisis funcional
- BDD base

### Semana 2

- API testing base

### Semana 3

- Newman y evidencia

### Semana 4

- Playwright smoke

### Semana 5

- flujo integrado y estabilización
